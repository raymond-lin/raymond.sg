How I work

Systems thinking, hands on the keyboard

I like the space where enterprise platforms meet hands-on software. I can work out how a CRM, ERP and commerce stack should fit together, and then write, test and deploy the app that sits on top.

On the enterprise side that means platform integrations, data moving cleanly between systems, release quality, and the unglamorous security basics that keep sites up: DNS, SSL, WAF and payment-gateway reviews.

On my own projects it means TypeScript end to end, Postgres with row-level security, serverless at the edge, and Vitest and Playwright running in GitHub Actions before anything ships. I started out writing Windows utilities, and some of them have now been downloaded hundreds of thousands of times. That taught me early that software outlives the excitement of building it.
